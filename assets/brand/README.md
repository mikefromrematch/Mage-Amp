# MAGE brand

Shared logos for every plugin in the MAGE suite.

- `mage_mark_original.png`, `mage_wordmark_original.png`: the originals (black ink on white).
- `*_light.png`: light ink on transparent, for dark UIs.
- `spell_sigil_light.png`: the Spell plugin symbol, painted by `spell_sigil_generator.py`.
